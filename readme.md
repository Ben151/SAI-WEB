# מדריך תגיות ומושגים חיוניים ב-HTML וב-CSS

מדריך זה ריכז עבורך את התגיות המרכזיות ב-HTML ואת מאפייני ה-CSS החשובים ביותר שחובה להכיר כדי לפתח ולתחזק אתרי אינטרנט ביעילות.

---

## חלק א': HTML — מבנה ואלמנטים בסיסיים

ה-HTML אחראי על שלד המסמך והמשמעות הסמנטית של התוכן.

### 1. מבנה בסיסי של עמוד
*   `<!DOCTYPE html>` — מגדיר את סממני המסמך כ-HTML5 מודרני.
*   `<html lang="he" dir="rtl">` — שורש המסמך, מגדיר את שפת העמוד (עברית) וכיוון הקריאה (מימין לשמאל).
*   `<head>` — אזור ההגדרות (לא מוצג ישירות בדף): קידוד, קישורים לגופנים, קבצי עיצוב וכותרת הלשונית.
*   `<body>` — גוף המסמך שמכיל את כל התוכן הגלוי למשתמש.

### 2. טקסט וכותרות
*   `<h1>` עד `<h6>` — כותרות (Headers) ברמות שונות. `<h1>` היא הכותרת הראשית והחשובה ביותר בעמוד.
*   `<p>` — פסקת טקסט (Paragraph).
*   `<strong>` — הדגשת טקסט (משמעות סמנטית של חשיבות).
*   `<span>` — אלמנט עזר פנימי (Inline) לעיצוב או לטיפול בחלק קטן מתוך טקסט.

### 3. קישורים ותמונות
*   `<a href="url">` — קישור (Anchor) לדף אחר או לאתר חיצוני.
*   `<img src="image.jpg" alt="תיאור">` — הטמעת תמונה. המאפיין `alt` חיוני לנגישות ולמקרה שהתמונה אינה נטענת.
*   `<picture>` — מעטפת שמאפשרת להציג תמונות שונות בהתאם לרזולוציית המסך (Responsive Images).

### 4. רשימות (Lists)
*   `<ul>` — רשימה לא ממוינת (Unordered List) עם נקודות עגולות.
*   `<ol>` — רשימה ממוינת (Ordered List) עם מספרים.
*   `<li>` — פריט בתוך רשימה (List Item).

### 5. טבלאות (Tables)
*   `<table>` — טבלה.
*   `<tr>` — שורה בטבלה (Table Row).
*   `<th>` — תא כותרת בטבלה (Table Header, מודגש וממורכז אוטומטית).
*   `<td>` — תא נתונים רגיל בטבלה (Table Data).

### 6. טפסים ואינטראקטיביות (Forms)
*   `<form>` — טופס לשליחת נתונים.
*   `<input type="text">` / `<input type="password">` — שדות הקלדה לטקסט או לסיסמה.
*   `<input type="checkbox">` / `<input type="radio">` — תיבת סימון או כפתור בחירה (Radio).
*   `<label for="id">` — תווית לשדה קלט. לחיצה עליה תבחר את השדה המקושר.
*   `<button>` — כפתור לביצוע פעולות.

## חלק ב': CSS — עיצוב, פריסה ואינטראקטיביות

ה-CSS אחראי על המראה החזותי, הצבעים, הפריסה והאנימציות של האתר.

### 1. בחירת אלמנטים (Selectors) ומשתנים
*   `*` — בורר כללי (Universal Selector).
*   `.classname` — בורר לפי מחלקה (Class).
*   `#idname` — בורר לפי מזהה ייחודי (ID).
*   `:root` — הגדרת משתנים גלובליים (Custom Properties) שניתן לעשות בהם שימוש חוזר בכל הקובץ (לדוגמה: `--neon: #00e676;`).

### 2. פריסה ומבנה (Layout & Display)
*   `display: flex;` — פריסה גמישה (Flexbox) שמאפשרת לסדר אלמנטים בשורה או בעמודה בקלות ולממרכז אותם.
*   `display: grid;` — פריסת רשת (CSS Grid) המאפשרת בניית מבנים דו-ממדיים מורכבים (עמודות ושורות).
*   `box-sizing: border-box;` — חובה לאפס בראש כל פרויקט כדי שהריפוד (Padding) והגבול (Border) ייכללו ברוחב הכולל של האלמנט.

### 3. מרווחים, גדלים ומיקום
*   `margin` / `padding` — שוליים חיצוניים ופנימיים.
*   `width` / `height` — רוחב וגובה.
*   `position: sticky;` / `position: fixed;` — הצמדת אלמנט למיקום קבוע במסך בזמן גלילה.
*   `z-index` — קובע איזה אלמנט יופיע מעל לאחר (שכבות).

### 4. עיצוב מתקדם ואפקטים
*   `background-image` / `background-size` — ניהול רקעים ותמונות ברקע.
*   `border-radius` — עיגול פינות של אלמנטים (לדוגמה: יצירת עיגול מלא בעזרת `50%`).
*   `box-shadow` / `filter: drop-shadow()` — הוספת צלליות ואפקטי זוהר (Glow).
*   `backdrop-filter: blur();` — טשטוש הרקע שמאחורי האלמנט (אפקט זכוכית / Glassmorphism).

### 5. עיצוב מותאם למסכים (Responsive Design)
*   `@media (max-width: 768px)` — נקודת עצירה (Media Query) המאפשרת לשנות את העיצוב והפריסה בהתאם לגודל המסך (למשל, מעבר ממחשב לטלפון נייד).
*   `clamp(min, preferred, max)` — פונקציה חכמה לקביעת גודל טקסט או ריפוד שמשתנה באופן דינמי בהתאם לרוחב המסך.

### 6. אנימציות ומעברים (Transitions & Animations)
*   `transition` — שינוי חלק והדרגתי של מאפיינים (כמו מעבר עכבר - Hover).
*   `animation` ו-`@keyframes` — יצירת אנימציות מורכבות שרצות באופן רציף (לדוגמה: נקודה מהבהבת או סיבוב מכ"ם).
